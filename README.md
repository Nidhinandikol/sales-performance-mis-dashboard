# Sales Performance & MIS Dashboard | Power BI

## Project Overview

This project explores sales performance through a Power BI dashboard designed to support KPI monitoring and management reporting.

## Objectives

- Monitor total sales and order-related KPIs.
- Analyse sales trends over time.
- Compare sales performance across regions.
- Evaluate performance by product category.
- Practise data transformation and visualisation using Power BI.

## Tools & Technologies

- **Power BI Desktop** — dashboard development and visualisation
- **Power Query** — data transformation and cleaning, where applied
- **DAX** — measures and calculations, where implemented
